# Ki Insurance

> Ki is Lloyd's Syndicate 1618 — the first fully digital, algorithmically driven syndicate at Lloyd's of London, launched in 2020 out of Brit with Google Cloud and University College London and capitalised with US$500m from Blackstone Tactical Opportunities and Fairfax Financial. Ki writes follow-only capacity across property, casualty and specialty lines, quoting risks a lead underwriter has already priced in seconds rather than days. Its API surface is real but entirely partner-gated: no developer portal, no reference documentation, no self-serve signup.

Generated: 2026-07-25. Method: generated (Ki publishes no llms.txt — /llms.txt is 404 on ki-insurance.com and an SPA catch-all on app.ki-insurance.com).

## What is actually available

Ki announced a "Broker API" on 4 May 2021 that lets partner broking platforms request follow-capacity quotes directly from its algorithm. Ki publishes nothing about it. What IS observable is the broker trading platform's own API: Ki's single-page app at app.ki-insurance.com ships a complete endpoint registry in its public JavaScript bundle, from which API Evangelist derived an OpenAPI of 102 paths and 109 operations. That spec is an API Evangelist derivation, not a Ki document, and every operation requires partner-gated Auth0 credentials.

- Access model: Auth0 authorization-code login, issuer https://login.ki-insurance.com/, audience https://api.ki.com, `Authorization: Bearer <JWT>` on every call
- Base URL: https://app.ki-insurance.com (same-origin `/api` surface — no separate API host)
- No API keys, no sandbox, no test credentials, no self-serve access
